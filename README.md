# -Construction-Task
Civil Engineering: Residential Buildings Apartment blocks: Multi-unit residential buildings, usually several stories high, housing multiple families or individuals.
Image Annotation Project Construction Task (CVAT)
Overview
Task requirements
This task is to annotate objects in an image using the Shape tool. 
Draw a tight bounding box around each individual building. 

Class list
Residential Buildings:
Apartment blocks
Housing units under construction
Commercial Buildings:
Office blocks
Shopping or mixed-use structures
Industrial Buildings:
Warehouse
Factories or large-span structures


Minimum size for objects are 20×20 pixels. 
Do not annotate images that are too far.
Labels:
1. Apartment Blocks (RB)
2. ⁠Housing units under construction (RB)
3. ⁠Office Blocks (CB)
4. ⁠Shopping or mixed use structure (CB)
5. ⁠Warehouse (IB)
6. ⁠Factories (IB)
Residential buildings (RB)
Commercial Building (CB)
Industrial Building (IB)
